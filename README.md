# Parcel

Things which are done by Parcel is ->
-Dev Build 

-Local Server

-HMR -Hot Module Replacement ->Automatically refreshes the browser when you save a file.
You don't need to reload the page manually.

-File Watching Algorithm - written in c++

-Caching - Fater Builds ->Stores previously built files.
Makes future builds much faster.

-Image Optimization

-Minification ->Removes unnecessary spaces and comments.
Makes files smaller and faster.

-Bundling ->Combines multiple files into optimized bundles.

-Compress

-Consistent Hashing

-Code Splitting ->Loads only the code that is needed.
Improves application performance.

-Differential Bundling -support older browser

-Diagnostic

-Error Handling

-Https

-Tree Shaking - removes unneceesary code
